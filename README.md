# נגריית טאלב אמארה / منجرة طالب اماره

אתר תיק עבודות יוקרתי לנגרות בהתאמה אישית — עברית וערבית בלבד. ללא מחירים.

## הרצה מקומית

```bash
python3 -m http.server 8080
```

## ניהול תמונות

1. פתחו `/admin.html`
2. התחברו עם הסיסמה שלכם
3. העלו תמונת פתיחה והוסיפו/ערכו פרויקטים (גלריה או מצלמה)
4. השינויים נשמרים בדפדפן במכשיר ומוצגים מיד באתר

## Deploy ב־Render

- Static Site
- Build: ריק
- Publish directory: `./`
