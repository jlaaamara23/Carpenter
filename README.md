# נגריית טאלב אמארה / منجرة طالب اماره

אתר תיק עבודות יוקרתי לנגרות בהתאמה אישית — עברית וערבית בלבד. ללא מחירים.

## הרצה מקומית

```bash
python3 -m http.server 8080
```

## פרסום תוכן לכולם

שמירה ב־Admin נשמרת רק בטלפון. כדי שכולם יראו:

1. Admin → **פרסום**
2. צרו GitHub Token (Contents: Read and write) לרפו הזה
3. הדביקו, שמרו Token, לחצו **פרסום לאתר לכולם**
4. Deploy ב־Render אם צריך

## Deploy ב־Render

- Static Site
- Build: ריק
- Publish directory: `./`
